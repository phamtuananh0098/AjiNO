# THƯ MỤC LƯU TRỮ NHẠC CƯỚI TĨNH TRÊN VERCEL CDN (24/7)

Bạn có thể lưu các tệp âm thanh trực tiếp từ máy tính vào thư mục này để được Vercel lưu trữ và phân phối trên mạng CDN toàn cầu 24/7:

1. Chép các file nhạc `.mp3`, `.m4a`, `.wav` của bạn vào thư mục này:
   `AjiNO/public/audio/ten_bai_hat.mp3`

2. Chạy file `DAY_LEN_GITHUB.bat` để đẩy lên GitHub.

3. Vercel sẽ tự động tạo link nhạc tĩnh 24/7:
   `https://aji-no.vercel.app/audio/ten_bai_hat.mp3`

4. Dán link này vào app Duyên Ca Studio, bài hát sẽ phát 24/7 trên mọi điện thoại, iPad mà KHÔNG cần máy tính phải bật!
